# Strings

String manipulation, built-in string methods, stringstream parsing, character frequency maps, and string algorithms.

## Files

### `Lecture1/` - String Basics
* `introString.cpp` - String declaration, `cin`, and `getline()`.
* `stringAsAdataType.cpp` - Working with standard `std::string`.
* `updationOfSinglechar.cpp` - Modifying individual characters.
* `builtInfunction.cpp` - Methods like `length()`, `push_back()`, `append()`.
* `reverseHalfOfString.cpp` - Reversing a substring or half of a string.
* `subStringQuestion.cpp` - Substring extraction using `substr()`.
* `questionBasedonto_string.cpp` - Number to string conversion (`to_string()`).
* `basicQuestion.cpp` - Basic practice scripts.

### `Lecture2/` - Advanced String Problems
* `anagram.cpp` - Valid anagram check using frequency counting.
* `differentNeighbour.cpp` - Comparing adjacent characters.
* `highestOccuringCharacter.cpp` - Finding the character with highest frequency.
* `longestCommonPrefix.cpp` - Longest common prefix problem.
* `maxInStringarray.cpp` - Max numeric value in string vector.
* `stringStream.cpp` - Parsing words with `std::stringstream`.
* `mostoccuringwordusingss.cpp` - Finding the most frequent word in a sentence.
* `sortingString.cpp` - Sorting string characters with `std::sort()`.
* `stoiANDstoll.cpp` - String to integer conversions (`stoi()`, `stoll()`).
* `revisionOfQuestions.cpp` - General review questions.

## Compile & Run
```bash
g++ String/Lecture2/anagram.cpp -o anagram
./anagram
```
