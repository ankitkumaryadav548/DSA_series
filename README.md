# Data Structures & Algorithms in C++

A collection of C++ programs covering fundamental data structures, sorting algorithms, recursion, search techniques, and standard array/string problems.

## Directory Overview

| Directory | Topic | Key Concepts |
| :--- | :--- | :--- |
| `timeANDspaceComplexity/` | Time & Space Complexity | Big-O notation, asymptotic analysis |
| `Function/` | Functions | Functions, default parameters, $nCr$ and $nPr$ |
| `PatternPrinting/` | Pattern Printing | Nested loops, star/number patterns, Floyd's triangle |
| `Array/` | 1D Arrays & Vectors | `std::vector`, 2-pointer problems, rotation, Dutch National Flag |
| `2dArray/` | 2D Arrays & Matrices | Matrix operations, row/column traversal, transpose, 2D vectors |
| `Array_classRoom/` | Array Basics | Hand-coded array operations (insert, delete, linear/binary search) |
| `SPECIAL_ALGORITHM_ARRAY/` | Array Algorithms | Prefix sum, sliding window techniques |
| `BINARY_SEARCH/` | Binary Search | Lower/upper bounds, rotated sorted arrays, mountain arrays |
| `BITWISE_OPERATOR/` | Bitwise Manipulation | Bitwise operators, binary to decimal conversion |
| `String/` | Strings | String methods, `stringstream`, anagrams, longest common prefix |
| `primeNumberANDsomeMath/` | Math & Primes | Prime checking ($O(\sqrt{N})$ complexity) |
| `Recursion/` | Recursion | Base cases, call stack, power calculation, maze paths, Tower of Hanoi |
| `SORTING/` | Sorting Algorithms | Bubble, Selection, Insertion, Merge, Quick, and Cycle sort |
| `LinkedList/` | Linked List | Singly linked list node structure, pointers, basic operations |
| `BinaryTree/` | Binary Trees & BST | Node structure, BFS (Level Order), DFS (Pre/In/Postorder), BST insertion |

## How to Run

Compile any `.cpp` file using `g++`:

```bash
# Example
g++ BINARY_SEARCH/Lecture1/binary_searchCode.cpp -o binary_search
./binary_search
```

On Windows (PowerShell):
```powershell
g++ BINARY_SEARCH\Lecture1\binary_searchCode.cpp -o binary_search.exe
.\binary_search.exe
```
