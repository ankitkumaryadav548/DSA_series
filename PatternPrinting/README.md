# Pattern Printing

Nested loop programs printing geometric shapes, star patterns, number grids, and alphabet shapes.

## Patterns Covered
* `solidSquare.cpp` - Solid $N \times N$ grid of stars.
* `triangle.cpp` - Right-angled star triangle.
* `starReverseTriangle.cpp` - Inverted right-angled star triangle.
* `AlphabetSquare.cpp` - Alphabet grids ($A, B, C, D$).
* `patternofNumber.cpp` - Grid of numbers.
* `oddNumberTriangle.cpp` - Triangle with odd numbers ($1, 3, 5, \dots$).
* `FloydTriangle.cpp` - Continuous sequence number triangle.
* `binaryTriangle.cpp` - Triangle with alternating 0s and 1s.
* `StarPlus.cpp` - Plus ($+$) shape pattern.
* `StarCross.cpp` - Diagonal cross ($X$) shape pattern.
* `TowerofHanoi.cpp` - Move sequence visualization for Tower of Hanoi.
* `pattern.cpp` - General pattern practice.

## Core Loop Structure
* **Outer loop (`i`)**: Controls row count.
* **Inner loop (`j`)**: Controls column content / spacing.

## Compile & Run
```bash
g++ PatternPrinting/FloydTriangle.cpp -o floyd
./floyd
```
