# Time and Space Complexity

Algorithm analysis, asymptotic notations (Big-O), and complexity trade-offs.

## Files
* `basicQuestion.cpp` - Code examples analyzing Big-O time and space complexity for loops and recursion.

## Common Time Complexities

| Complexity | Growth Rate | Example |
| :--- | :--- | :--- |
| $O(1)$ | Constant | Array index access |
| $O(\log N)$ | Logarithmic | Binary search |
| $O(\sqrt{N})$ | Square Root | Primality test |
| $O(N)$ | Linear | Single loop traversal |
| $O(N \log N)$ | Linearithmic | Merge sort |
| $O(N^2)$ | Quadratic | Nested loops, bubble sort |
| $O(2^N)$ | Exponential | Recursive Fibonacci, subsets |

## Compile & Run
```bash
g++ timeANDspaceComplexity/basicQuestion.cpp -o complexity
./complexity
```
