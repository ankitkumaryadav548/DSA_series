# Functions in C++

Basics of functions, built-in functions, default parameters, and mathematical combinations.

## Files
* `basic_function.cpp` - Function syntax, return types, and arguments.
* `builtinLibrary.cpp` - Standard functions like `max()`, `min()`, `swap()`, `pow()`, `sqrt()`.
* `defaultValue.cpp` - Functions with default argument values.
* `factorial.cpp` - Factorial function ($n!$).
* `permutationAndcomibination.cpp` - Permutations ($nPr = \frac{n!}{(n-r)!}$) and Combinations ($nCr = \frac{n!}{r!(n-r)!}$).

## Compile & Run
```bash
g++ Function/permutationAndcomibination.cpp -o nCr
./nCr
```
