# Recursion

Recursive function calls, base cases, call stacks, grid paths, and array processing.

## Files

### `Lecture1/` - Fundamentals
* `greet.cpp` - Basic recursive call.
* `functionCall.cpp` - Call stack behavior.
* `print1ToN.cpp` / `printNTo1.cpp` - Printing $1$ to $N$ and $N$ to $1$.
* `sumOf1ToN.cpp` - Calculating sum recursively.
* `factorialRec.cpp` - Recursive factorial ($N!$).
* `practisecode.cpp` / `revise.cpp` - Practice scripts.

### `Lecture2/` - Advanced Recursion & Trees
* `power.cpp` / `pow.cpp` - Linear recursive power calculation ($O(N)$).
* `powLog.cpp` - Logarithmic power calculation ($O(\log N)$).
* `fibonaciSeries.cpp` - Fibonacci number calculation.
* `stairPath.cpp` - Staircase problem (1 or 2 steps).
* `stairPathWith3Step.cpp` - Staircase problem (1, 2, or 3 steps).
* `mazePath.cpp` - Grid maze path counting.
* `preInPost.cpp` / `zigzagpreInpost.cpp` - Euler tree traversal order.

### `Lecture3/` - Array & Puzzles
* `printArray.cpp` - Printing array elements recursively.
* `maxValueInArray.cpp` - Finding max element in an array recursively.
* `TowerOfHanoi2.cpp` - Tower of Hanoi puzzle solution.

## Compile & Run
```bash
g++ Recursion/Lecture2/powLog.cpp -o pow_log
./pow_log
```
